# English Primary 1 – Game World

A complete static educational games platform based on the Egyptian **English Primary 1 – Term 1 (2025/2026)** curriculum.

## Included
- 6 units and 24 lessons.
- 2 games per lesson: **48 lesson games**.
- Review 1 and Review 2 tournaments.
- 14 reusable game engines: phonics action, racing, runner, maze, builder, story, memory, detective, puzzle, simulation, dialogue, penalty, football and tournament.
- Grade-1 phonics audio, word pronunciation and audio-first questions.
- Touch, mouse and keyboard support.
- XP, coins, gems, stars, levels, badges, best scores and sequential unit progress.
- No login screen. Identity can be passed with `studentId`, `studentName` and `className` query parameters or `window.PLATFORM_STUDENT`.
- LocalStorage fallback per student.

## Run locally
```bash
python -m http.server 8765
```
Open `http://localhost:8765`.
