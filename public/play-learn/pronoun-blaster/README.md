# Pronoun Blaster — Bright Grammar Galaxy

A child-friendly HTML5 shooting game for practising English subject and object pronouns.

## What is included

- 10 progressive missions from Starter to Champion.
- 134 carefully written questions in the full question bank.
- Subject pronouns, object pronouns, paired forms, prepositions, mixed practice and sentence correction.
- Responsive full-screen play on laptops, tablets and mobile phones.
- A dynamically resized Canvas so the energy blaster stays visible without scrolling.
- Score, four lives, combos, stars, feedback and saved progress.
- Bright child-friendly colours and touch controls.

## Run the game

Open `index.html` in a modern browser. No installation or server is required.

## Main files

- `index.html` — structure and screens
- `styles.css` — responsive bright visual design
- `game.js` — question bank, levels, Canvas engine and progress system
