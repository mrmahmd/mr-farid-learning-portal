# Primary 4 English - Interactive Assessment Workbook

A complete offline-ready HTML/CSS/JavaScript conversion of the first-term Performance Tasks and Assessment book (2025-2026).

## Run locally

Open `index.html` directly, or start a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Project structure

- `index.html` - main entry
- `css/styles.css` - complete responsive design
- `js/book-data.js` - all units, lessons, questions, answer keys, writing prompts and exams
- `js/app.js` - interactive engine, scoring, saving, drawing, feedback and navigation
- `assets/pages/` - optimized original-page references
- `manifest.webmanifest` and `sw.js` - offline/PWA support

## Features

- Seven main sections: Units 1-6 plus Model Exams
- 58 learning stations
- MCQ, word bank, correction, reordering, True/False, reading, open answers, writing and drawing
- Instant feedback and answer keys for objective activities
- XP, stars, progress and sequential unlocking
- Automatic local saving
- Responsive mobile/desktop layout
- Original page reference inside every station
