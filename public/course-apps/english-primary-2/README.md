# English Primary 2 - Term 1 Complete Interactive Website

This project converts the complete 2025/2026 Ministry textbook into a static interactive website.

## Included
- 6 units and 24 lessons, mapped to the original book pages.
- Unit learning outcomes, values, lesson vocabulary, language in use, phonics, reading, writing, and adapted book activities.
- 25 fixed questions for every lesson (600 total).
- 30 fixed questions for every unit challenge (180 total).
- Two cumulative 50-question book reviews (100 total).
- Local progress, stars, sequential lesson unlocking, last-lesson continuation, text-to-speech, writing pads, and glossary.
- Original high-resolution 3D unit artwork displayed with `object-fit: contain` so it is not cropped in unit cards.

## Run
Open `index.html`, or serve the folder with any static server.

## Hosting
The folder can be uploaded directly to GitHub Pages, Netlify, Cloudflare Pages, or another static host.

## Important
Progress is stored locally in the student's browser. No database or account system is included in this version.
