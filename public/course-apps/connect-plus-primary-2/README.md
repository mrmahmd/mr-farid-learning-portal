# Connect Plus 2 – Pixar Visual Edition V3

Interactive English course for **Primary 2 – First Term** based on the uploaded Connect Plus 2 curriculum.

## What changed in V3

- No student-name entry screen; the course opens directly to the dashboard and can receive student information from the parent platform.
- Six custom 3D-style unit covers. The app no longer uses book-page crops as unit or lesson covers.
- 229 newly rebuilt picture-based vocabulary assets. Vocabulary cards now show a large visual clue, the word, simple meaning, example, and pronunciation button.
- Lesson hero artwork is derived from the new visual system rather than scanned textbook pages.
- Picture clues are also used inside Choose, Complete, and Look & Write practice where a matching vocabulary visual exists.
- 18 core lessons, 30 questions per lesson, 50-question banks, reviews, non-fiction reader, and The Gingerbread Man story.
- Local progress saving plus platform integration through URL parameters, JavaScript data, or postMessage.
- Responsive desktop/tablet/mobile layout.

## Run

Open `index.html`, or serve the folder with any static server. For GitHub Pages, upload the **contents of this folder** so `index.html` sits at the repository root.
