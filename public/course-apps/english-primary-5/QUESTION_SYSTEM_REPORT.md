# Question System Quality Report

## Coverage

- 6 units
- 30 lessons
- 20 questions per lesson
- 600 curriculum-grounded lesson questions
- 50-question master challenge for each unit

## Question order inside every lesson

| Group | Questions |
|---|---:|
| Choose | 4 |
| Complete | 4 |
| True / False | 3 |
| Matching | 1 |
| Drag & Drop | 1 |
| Listening | 1 |
| Ordering | 2 |
| Correction | 2 |
| Sentence Builder | 2 |
| **Total** | **20** |

## Design rules applied

- Questions use real lesson content, grammar, reading details, writing steps, projects, and story events.
- Vocabulary is tested in sentences and situations rather than through dictionary definitions.
- Exercise types are grouped and are not randomly mixed.
- Correction activities highlight only the incorrect word or phrase.
- Students type only the corrected word or phrase.
- Listening scripts are short, natural, and based on the lesson.
- Drag-and-drop also has a tap fallback for mobile devices.
- Correct answers move automatically after five seconds.
- Wrong answers show the answer and explanation, then require **GOT IT**.
- Points are awarded only once for each question.
- Current-question position and score are saved automatically.

## Automated checks completed

- All 30 question banks exist.
- Every lesson has exactly 20 questions.
- All groups appear in the required order.
- Each unit challenge can select exactly 50 questions.
- No prompts use “Which word means…?”, “Choose the definition”, or “What is the meaning of…?”.
- JavaScript syntax checks passed for the application, curriculum, question bank, and service worker.
